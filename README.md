# Jenkins CI/CD Pipeline

## Objective
Automate application testing, building, and deployment
using Jenkins and Docker.

## Technologies Used
- Jenkins
- Docker
- Node.js
- Git and GitHub

## Pipeline Stages
1. Checkout source code from GitHub.
2. Test JavaScript syntax.
3. Build the Docker image.
4. Deploy the application using Docker.

## Application
Open http://localhost:3000 in a browser.

## Outcome
Created a basic CI/CD pipeline using Jenkins and Docker.
